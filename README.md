# Cloud-Based College Note Sharing System

A simple web-based platform designed for college students to explore and share academic notes.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python Flask
- Render

## Features

- Six academic subject categories
- Student-friendly interface
- Note sharing form
- Interactive buttons
- Flask backend
- Cloud deployment ready

## Cloud Deployment

Deployed using Render.

## Future Developments

Future versions can include actual note uploads, database storage, student authentication, download options, and an expanded college portal.
